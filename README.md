# Kael — Sombras do Além

Plataforma 2D de ação em pixel art feito em **Unity 6 (URP 2D)**.

Durante séculos, o **Selo das Duas Luas** manteve o Reino das Sombras separado do mundo humano. Numa noite de eclipse, o selo se partiu. **Kael**, um jovem guardião do Templo da Lua, desperta sem memória e parte em busca dos **Fragmentos da Lua** para restaurar o selo.

## Controles

| Ação | Teclas |
|---|---|
| Andar | A / D ou ← / → |
| Pular | Espaço, W ou ↑ |
| Golpe de espada | J ou clique esquerdo |
| Esquiva | K, Shift ou clique direito |
| Pausa / opções | ESC |
| Tela cheia | F |

**Parry:** comece um golpe logo antes de um inimigo acertar o Kael para bloquear o dano. Nos chefes, o parry os deixa atordoados.

## Como abrir

1. Instale o **Unity 6** (6000.0.32f1 ou mais recente).
2. Abra esta pasta pelo Unity Hub (*Add project from disk*).
3. Abra a cena `Assets/_Scenes/__Title` e aperte Play.

Mais detalhes de história, direção de arte e regras de jogo em [contexto.md](contexto.md).
